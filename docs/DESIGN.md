# ডিজাইন সিস্টেম — Saimum CRM

শৈলী: **Soft UI Evolution** (আধুনিক ও উজ্জ্বল; নরম বহুস্তর ছায়া, ১০–১৬px গোলাই, ২০০ms ট্রানজিশন),
রঙের ভিত্তি: **WhatsApp-এর নিজস্ব ব্র্যান্ড-রং** (ব্যবহারকারীর পছন্দ)।
স্কিল: `ui-ux-pro-max` (style `soft-ui-evolution`, typography "Friendly SaaS", google-fonts বাংলা সাবসেট,
pre-delivery checklist)।

## রঙের ইতিহাস (কেন বদলেছে)

১. ইন্ডিগো (স্কিলের পেলেট থেকে সরে, Messenger-নীলের সাথে না গুলানোর জন্য) → ব্যবহারকারীর পছন্দ হয়নি।
২. Claude-এর ক্লে/আইভরি → পছন্দ হয়নি।
৩. **এখন: WhatsApp-এর সবুজ-টিল**, কারণ এই CRM-এর প্রধান চ্যানেল WhatsApp এবং কর্মীরা WhatsApp Web-এর সাথে পরিচিত।

৪. **এখন (সর্বশেষ): উষ্ণ কমলা**, ব্যবহারকারীর দেওয়া ড্যাশবোর্ড-মকআপ থেকে। নিচের সিদ্ধান্ত-টেবিলে WhatsApp-টিল
যেখানে লেখা, সেখানে একই ভূমিকায় এখন কমলা: লোগো/সাজসজ্জা `#FF6A13` (তার ওপর সাদা লেখা ২.৮৭:১, ফেল, তাই আইকন গাঢ়
`#1B1A17`), লেখা/বোতাম/লিংক `#C2410C` (hover `#9A3412`), dark-এ `#FF8A3D` + গাঢ় লেখা। পটভূমি উষ্ণ অফ-হোয়াইট `#FAF9F6`
(dark `#141311`), পাঠানো বাবল পীচ `#FFE9D6` (dark `#5A2E12`)। WhatsApp/Messenger চ্যানেল-বিন্দু আগের মতো সবুজ/নীল।

## থিম সুইচ

দুটি থিম, ব্যবহারকারী নিজে বদলায় (সাইডবারে আলো|অন্ধকার, মোবাইল টপ-বার ও লগইনে এক-ট্যাপ বোতাম)। ডিফল্ট **light**, OS-এর
সেটিং উপেক্ষিত। `data-theme` `<html>`-এ, `localStorage` কী `theme`; `<head>`-এর ছোট inline script paint-এর আগে বসায় (ফ্ল্যাশ নেই)।
`dark:` ভ্যারিয়েন্ট এই অ্যাট্রিবিউটের অনুসারী। ব্রাউজারে যাচাই: বদলায়, রিলোডে থাকে।

## কনট্রাস্ট (মাপা)

`npm run design:contrast` (`scripts/check-contrast.mjs`) প্রতিটা লেখা/পটভূমির জোড়া WCAG অনুপাতে মাপে: লেখা ≥ ৪.৫:১,
গ্রাফিক ≥ ৩:১। **light ও dark মিলিয়ে ৫৪টি জোড়াই মেটে।** রং বদলালে স্ক্রিপ্টের মান ও `globals.css` একসাথে বদলাও।
স্ক্রিপ্ট ফেল করলে exit code ১ দেয়।

## উপাদান ও নিয়ম

- উপাদান: `src/components/ui.tsx` (`buttonClass`, `fieldClass`, `Field`, `Card`, `Badge`, `Alert`, `PageHeader`,
  `EmptyState`, `Avatar`, `ChannelBadge`, `LogoMark`)। আইকন `lucide-react`; **ইমোজি আইকন হিসেবে নয়**।
- পেজে কাঁচা রং (`zinc-*`, `green-*`...) নয়, শুধু টোকেন (`bg-surface`, `text-muted`, `bg-brand`, `bg-bubble-out`...)।
- টাচ-টার্গেট ≥ ৪৪px (`md`), ঘন সারিতে `sm` ৩৬px। সব ক্লিকযোগ্য জিনিসে `cursor: pointer` (global CSS)।
- ফোকাস: সর্বত্র ২px দৃশ্যমান রিং; ইনপুটে অতিরিক্ত নরম glow।
- শেল: lg+ সাইডবার; তার নিচে টপ-বার + ড্রয়ার (`mobile-bar.tsx`, Esc/ফোকাস/স্ক্রল-লক)।
